## 4. Sizdan kerak bo'lgan qadamlar (internet, bot, pochta)

**A. Cloudflare (sayt internetga chiqishi uchun)**
1. dash.cloudflare.com da bepul hisob oching → "Add a site" → `reyspro.uz` → Free tarif.
2. Cloudflare ko'rsatgan 2 ta NS (nameserver) manzilini domenni olgan joyingizdagi (registrator) domen sozlamalariga yozing. Faollashishi bir necha soatgacha.
   (Hozir reyspro.uz DNS'da hali topilmayapti — ro'yxatdan o'tish yakunlanishini kuting.)
3. Zero Trust → Networks → Tunnels → **Create a tunnel** → Cloudflared → nom: `reyspro` → Windows. Ko'rsatilgan buyruqdagi tokenni nusxalang (chatga yozmang).
4. Shu tunnelda **Public Hostnames** qo'shing (uchalasi ham `http://localhost:3000` ga):
   `crm.reyspro.uz`, `reyspro.uz`, `www.reyspro.uz`.

**B. Brevo (pochta)**
1. brevo.com da bepul hisob → Senders, Domains → **Add a domain** → `reyspro.uz`.
2. Brevo bergan DNS yozuvlarini (Brevo code, DKIM, DMARC) Cloudflare → DNS ga qo'shing. SPF: `v=spf1 include:spf.brevo.com ~all` (TXT, nom `@`).
3. Brevo'da domen "Authenticated" bo'lgach: SMTP & API → SMTP — **Login** va **SMTP key** yarating.

**C. Skriptni ishga tushirish** (Administrator PowerShell):
```
powershell -ExecutionPolicy Bypass -File C:\logistika\scripts\internet-sozlash.ps1
```
U Telegram tokenni, Brevo login/kalitini, Cloudflare tunnel tokenini so'raydi (har birini o'tkazib yuborish mumkin), tekshiradi, saqlaydi va serverni qayta ishga tushiradi.

**D. Ro'yxatdan o'tish**: Super Admin → Sozlamalar → Rekvizitlar to'ldirilsin. Ofertani yurist ko'rib chiqishi tavsiya etiladi.
